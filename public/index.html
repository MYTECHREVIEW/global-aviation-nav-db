Developer REST API

GET /api/v1/simbrief/fetch?username=myuser

Pull the latest flight plan from SimBrief by username or pilot ID.

POST /api/v1/simbrief/trace

Pull latest OFP from SimBrief and automatically trace route into waypoints & GeoJSON.

POST /api/v1/route/trace

Traces flight plan route and returns geodesic coordinates, distance, and GeoJSON.

GET /api/v1/waypoints/search?q=MERIT

Search global waypoints, VORs, NDBs, and airports.

GET /api/v1/waypoints/:ident

Fetch details and location of any waypoint or NavAid.

GET /api/v1/airport/:icao/navaids

Get all NavAids associated or within 30 NM of an airport.

GET /api/v1/airways/:ident

Get fix sequence along an enroute airway (e.g. J79).
