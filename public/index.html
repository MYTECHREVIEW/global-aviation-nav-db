🐳 Docker Compose & Dockage Stack

Copy and paste this configuration directly into Portainer Web Editor, Dockage, or your server's docker-compose.yml.

version: '3.8'

services:
  global-aviation-nav-db:
    image: ghcr.io/mytechreview/global-aviation-nav-db:latest
    container_name: global-aviation-nav-db
    restart: unless-stopped
    ports:
      - "3510:3510"
    environment:
      - PORT=3510
      - NODE_ENV=production
      - MAPBOX_ACCESS_TOKEN=
    volumes:
      - aeronav_keys:/app/data/keys
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3510/health"]
      interval: 30s
      timeout: 5s
      retries: 3

volumes:
  aeronav_keys:
    name: aeronav_api_keys

🔑 Authentication

Pass API Key via X-API-Key header or ?api_key= parameter. Public telemetry endpoints allow direct CORS pass-through.

🌐 Multi-Network Live Target Array API

POST /api/v1/live/multi

Concurrently tracks any combination of VATSIM CIDs/callsigns, FSHub tokens/user IDs/VAs, and IVAO IDs in a single batch request.

📡 Data Pass-Through & Flight Planning Endpoints

POST /api/v1/route/trace

Traces flight plan with SIDs, Airways, STARs, and international fixes into geodesic coordinates and GeoJSON corridors.

POST/GET /api/v1/fshub/inspect

Pass FSHub Token to fetch user profile, stats, personal flight, and active VA fleet flights.

POST /api/v1/simbrief/trace

Auto-import and trace SimBrief OFP in 1 step.

GET /api/v1/waypoints/search?q=MATLK

Search global navigation fixes, VORs, NDBs, and airports.

GET/POST /api/v1/waypoints/custom

Inspect or add/update custom persistent navigation waypoints in data/custom-global-waypoints.json.
