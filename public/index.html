🐳 Docker Compose & Dockage Stack

Paste this directly into the Portainer Web Editor, Dockage, or your local docker-compose.yml file.

version: '3.8'

services:
  global-aviation-nav-db:
    # Build directly from GitHub or local directory
    build: https://github.com/MYTECHREVIEW/global-aviation-nav-db.git#main
    image: global-aviation-nav-db:latest
    container_name: global-aviation-nav-db
    restart: unless-stopped
    ports:
      - "3510:3510"
    environment:
      - PORT=3510
      - NODE_ENV=production
      - MAPBOX_ACCESS_TOKEN=
    volumes:
      # Persist API keys across container rebuilds
      - aeronav_keys:/app/data/api-keys.json
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3510/health"]
      interval: 30s
      timeout: 5s
      retries: 3

volumes:
  aeronav_keys:
    name: aeronav_api_keys

🔑 Authentication

All /api/v1/* endpoints require an API Key (generate one in the API Keys & Git tab).

HTTP Header (Recommended): X-API-Key: aeronav_live_YOUR_KEY
Query Parameter: ?api_key=aeronav_live_YOUR_KEY

📡 REST API Endpoints

POST /api/v1/route/trace

Traces a flight plan route string with SIDs, Airways, STARs, and outputs sequential waypoints, bearings, distances, and GeoJSON.

Request Body (JSON): 
{
  "departure": "KEYW",
  "arrival": "KLGA",
  "route": "KEYW/09 BUFTT1 MATLK Q87 HURTS PROUD2 KLGA/04",
  "altitude_ft": 38000,
  "airspeed_kts": 460
}
POST /api/v1/simbrief/trace

Fetches the user's latest flight plan from SimBrief and automatically traces the entire route into waypoints and GeoJSON in one step.

Request Body (JSON): 
{
  "username": "my_simbrief_pilot_id"
}
GET /api/v1/simbrief/fetch?username=myuser

Fetches raw OFP flight plan details (origin, destination, runways, route, altitude, airspeed, aircraft) from SimBrief.

GET /api/v1/waypoints/search?q=MATLK

Searches global airports, VORs, NDBs, and waypoints by name or ident.

GET /api/v1/waypoints/:ident

Get high-precision GPS coordinates, frequency, and airport associations for any waypoint.

GET /api/v1/airport/:icao/navaids

Retrieve all VOR, VORTAC, and NDB navigation aids located within 30 NM of an airport.

GET /api/v1/airways/:ident

Get ordered fix sequence along an enroute airway (e.g. Q87 or J79).

POST /api/v1/auth/keys

Generate a new API key programmatically.

Request Body (JSON): 
{
  "name": "My Client App",
  "expires_in_days": 365
}
